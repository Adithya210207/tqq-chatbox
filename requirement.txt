#  [2] SOFTWARE
# -------------------------------------------------------------------------------------
#
#   Ollama ................. 0.40.16 or newer         https://ollama.com
#       Runs the AI models on your computer.
#       Setting: OLLAMA_MAX_LOADED_MODELS = 1   (user environment variable)
#       Setting: OLLAMA_MODELS = C:\ollama-new-models   (or Ollama's default folder)
#       Version 2 of the app starts its OWN private Ollama (port 11435, 2 models)
#       and stops it when you close the app; your normal Ollama stays at 1 model.
#
#   Java JDK ............... 26 (26.0.1)              only to BUILD the app
#       The .exe already has Java inside it. You only need the JDK to run
#       build.bat / run.bat / package.bat after changing the code.
#
#   JavaFX SDK ............. 26.0.1                   already included
#       In  TQQ Chat App\...\lib\javafx-sdk-26.0.1\  (from gluonhq.com)
#
#   Python ................. 3.12 or newer (3.14.6 used)   only for the training
#       data pipeline and the test scripts (Lora fine-tuning assest\v2_pipeline\).
#       Not needed to chat.
#
#   Google Colab ........... free account, T4 GPU     only to TRAIN a sister
#       Notebook: Lora fine-tuning assest\v2_pipeline\train_qlora_colab.ipynb
#       It installs its own tools there:  unsloth · trl · datasets · transformers
#
#   Fonts (Windows) ........ Segoe UI · Bahnschrift · Bodoni MT · Yu Gothic UI
